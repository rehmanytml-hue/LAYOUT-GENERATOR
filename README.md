# Stitching Line Layout Builder

A browser tool that draws a garment stitching-line layout from an Excel operation bulletin and checks the line balance.

**Open the tool:** the GitHub Pages link for this repository (Settings → Pages).

## How to use
1. Download **Stitching_Line_Layout_Template.xlsx** (button on the page) and fill in Line_Info, Operations and Machine_Master.
2. Open the tool and click **Load Excel file**.
3. Choose layout type, operator orientation and far-side direction.
4. Export with **Generate Visio layout** (editable .vsdx inside a .zip) or **Download PDF**.

Excel files are read in your browser only – nothing is uploaded.
